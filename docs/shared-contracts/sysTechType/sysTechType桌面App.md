# I. 主旨目的

定義「桌面App」**基底系統類型**：Windows 桌面單機應用（構件＝[modTechStackWinApp]，產物＝Windows 散佈包）。平凡桌面工具宣告本基底即可；一經宣告即綁定：(1) **桌面通則能力清單**、(2) **安裝與更新機制**、(3) **介面水準 bar**；**具常駐喚起互動**（系統匣常駐、全域熱鍵、即查即走）之系統另過 ＜III.E節＞ 選配節逐項對照。

本契約是「該類系統該長什麼樣」的 normative 單一事實來源；GATE／design 引用本契約、不另抄一份。

# II. 參考準備

* **適用場景**：Windows 桌面單機程式——查詢工具、轉換工具、看板/播放器、輔助小工具等；單機執行、無伺服器端（需後端者屬 web 類 sysTechType）。
* **公開參照（不重造輪子）**：Windows 11 Fluent Design（type ramp／圓角／acrylic 層次）、WCAG 對比可近用性、Windows 安裝與更新慣例（安裝程式／可攜 zip、GitHub Release 散佈）；常駐類另見 ＜III.E節＞ 之 tray app／全域熱鍵／螢幕選取慣例。
* **四層鏈**（stackVersion 3.0）：sol 之 solTechStyle 定風格（本類型視覺錨宿主 OS 設計語言、solTechStyle 可標不適用）→ sysTechType（本層＝系統類型）→ mod 綁 modTechStack（桌面構件＝WinApp）→ 點名 cmpTechItem（mod 內函式庫，如語音合成）。

# III. 內容程序

## A. 桌面通則能力清單（逐項對照）

* **明確錯誤降級**：外部依賴（API、網路、金鑰）失效時給出明確可讀錯誤與下一步指引，不當機、不無聲失敗。
* **金鑰安全**：外部服務金鑰一律取自環境變數或 OS 憑證保管，程式檔、設定檔與 repo 不落地金鑰。
* **多螢幕與 DPI 正確**：視窗、遮罩、選區在多螢幕與非 100% DPI 縮放下座標對位正確。
* **關於與版本標示**：關於視窗（或同等處）標產品正式名稱、版號、版權·授權；版號與散佈包一致（跟隨 `VERSION`）。

## B. 安裝與更新機制（散佈通道＝deployWinDist，見 [TECHSTACK]）

* **散佈形式**：安裝程式**或**可攜 zip（擇一或並行，於 design.md ＜II.C.(B).4＞ 宣告）；散佈包檔名帶版號。
* **安裝程式（採用時）**：含開始選單捷徑與標準解除安裝項；解除安裝移除程式檔與捷徑，使用者資料／設定之留存與否明示。
* **可攜版（採用時）**：解壓即用、不落檔於系統目錄；設定檔隨程式目錄或使用者目錄，位置記入產品手冊。
* **更新機制**：內建版本檢查（啟動時或手動「檢查更新」，比對 GitHub Release 最新版號）＋導引下載安裝；**不做強制背景自動更新**（單機工具、受控環境原則）。
* **驗收**：安裝→使用→更新檢查→解除安裝全循環記入產品手冊並以 e2e／截圖佐證。

## C. 介面水準 bar（逐頁判讀）

* **視覺融入 OS**：遵循宿主 OS 設計語言（Windows＝Fluent：Segoe UI 字階、4px 間距格、圓角、暗色支援）；禁自創突兀配色與非標準控制項（design.md 明選 solTechStyle 覆寫者除外，見 [modTechStackWinApp] 對外介面綁定）。
* **狀態可見**：長時間運作有非阻斷進度回饋（可取消進度視窗或 spinner＋文字）；完成、失敗狀態一目了然。
* **明列不合格樣式（出現即回修）**：無 loading 狀態的長白等、錯誤只寫 "Error"、非標準控制項堆疊、DPI 錯位。

## D. 驗收綁定

* **GATE ＜5節＞ 鏡頭A**：逐項對照 ＜A節＞＋＜B節＞（常駐類另加 ＜E節＞）。
* **GATE ＜5節＞ 鏡頭C**：逐頁以 ＜C節＞（常駐類另以 ＜E節＞ 不干擾 bar）判讀，不合格項回修。
* **視覺基座**：桌面原生應用不錨 [hmiIntf通用視覺規範]（MD3 web 基座），改錨宿主 OS 設計語言；可近用性維持 WCAG 對比精神。

## E. 選配節：常駐即查工具（凡具「常駐背景＋喚起互動」之系統適用，逐項對照；不適用者跳過本節）

* **常駐輕量**：以系統匣常駐背景，閒置時記憶體占用 <100MB、CPU 近 0；不開常駐主視窗；tray 圖示必附選單。
* **喚起即時**：全域熱鍵按下至介面（遮罩／視窗）出現 <300ms；查詢流程全程不需滑鼠離開主活動視窗以外的操作。
* **零輸入干擾**：熱鍵註冊採系統標準 API（`RegisterHotKey`），**禁用低階鍵盤 hook**（`SetWindowsHookEx WH_KEYBOARD_LL`）除非設計明確要求並經 USR 核准——不得拖慢全系統輸入。
* **隨時可逃**：任一階段 `ESC` 立即取消／關閉，回到喚起前狀態；不留殘影視窗。
* **不干擾介面 bar**：喚起介面極簡（變暗底＋高對比選框＋一行操作提示，禁塞工具列／選項）；結果視窗即讀即走（單卡片、預設出現於選區旁不遮擋原文、`ESC` 或點擊外部即關）。
* **不合格樣式（出現即回修）**：喚起延遲可感（>500ms）、選區與實際截圖錯位、結果視窗遮住原選區。
* **點名 cmpTechItem（依輸出型態）**：查詢輸出含「發音／朗讀」者必含 [cmpTechItem語音合成]；其餘依 design 各層落地。
